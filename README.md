# vaktinde-legal

Vaktinde uygulamasının yayınlanmış yasal sayfaları (Gizlilik Politikası, Kullanım Koşulları, önceki sürüm hesapları için veri silme), Türkçe ve İngilizce. GitHub Pages ile yayınlanır.

Gizlilik ve koşullar sayfaları, uygulamanın içinde offline gösterilen metinlerden üretilir: ana uygulama deposundaki `src/features/legal/documents.ts`.
